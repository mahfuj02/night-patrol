# Vercel setup

1. Push the repo to GitHub (`mahfuj02/night-patrol`).
2. On vercel.com choose **Add New → Project** and import the repo.
3. Framework preset: Next.js (auto-detected). Install command: `pnpm install`. Leave build and output settings at defaults.
4. Deploy. Every PR then gets a preview URL as a bot comment.
5. In **Settings → Git**, keep Production Branch = `main`.
6. A custom domain is added in Phase 11.
