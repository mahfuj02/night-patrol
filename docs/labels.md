# Labels

Create these in GitHub (Issues → Labels). The `gh` commands are in CONTRIBUTING.md.

| Label        | Colour    | Use                              |
| ------------ | --------- | -------------------------------- |
| `scene`      | `#4FE3E3` | 3D scene, landmarks, car, camera |
| `ui`         | `#FFB25C` | HTML UI: HUD, panels, mini-map   |
| `content`    | `#E8EEF5` | Copy, projects, skills, stops    |
| `perf`       | `#FF8A5B` | Performance and budgets          |
| `a11y`       | `#8A4B3A` | Accessibility                    |
| `infra`      | `#14233F` | CI, tooling, repo setup          |
| `bug`        | `#D73A4A` | Something is broken              |
| `good-first` | `#7057FF` | Good first issue                 |
